## 修复 mi-local-control Android 版台灯控制失败问题

### 问题根因
对比 Python 版（python-miio）与 Android Kotlin 实现，发现 4 处关键差异导致设备不响应：

1. **Checksum 计算错误**：Android 版只计算 `MD5(header + token)`，正确应为 `MD5(header + token + encrypted_data)`
2. **缺少握手流程**：Android 版直接使用固定 `0xFFFFFFFF` deviceId 和本地时间戳，未从设备获取真实值
3. **加密 payload 缺少末尾 `\x00`**：python-miio 在加密前会在 JSON 后追加 `\x00`
4. **`discover()` 实现错误**：发送了加密的 `miIO.info` 请求而非标准 32 字节 hello 包

### 修复内容
- `MiIoCrypto.kt`：encrypt 追加 `\x00`，decrypt 去除尾部 `\x00`
- `MiIoPacket.kt`：checksum 计算加入 `encrypted_data`
- `MiIoClient.kt`：
  - 移除构造函数中的 `deviceId` 参数（改由握手获取）
  - 重写 `discover()` 为标准握手包（32 字节固定 hello）
  - 新增 `sendHandshake()` 从设备响应获取真实 `deviceId` 和 `timestamp`
  - `sendAndReceive()` 发送前自动握手，时间戳基于设备时间每次递增 1 秒
